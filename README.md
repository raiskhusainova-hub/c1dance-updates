## Автообновление

- Новые пакеты совместимости скачиваются только при появлении более новой версии.
- При запуске программа предлагает новую версию кнопками «Да/Нет». «Да» загружает и устанавливает её, «Нет» открывает текущую версию.
- Данные обновления и резервная копия хранятся в AppData/Local/Compatibility/Updates. Постоянная папка рядом с EXE не создаётся.
- При отсутствии связи программа использует доступный встроенный или сохранённый пакет.
- Подписи и контрольные суммы проверяются до установки. Настройки лицензирования сохраняются.

Для скачивания не нужен аккаунт GitHub. Старые EXE без автообновления нужно один раз заменить выпуском 2026101802 или более новым.

В репозитории размещены готовые выпуски. Исходники, приватный ключ подписи и профили браузеров здесь не публикуются.

Начиная со сборки 2026101806 EXE не скачиваются в фоне без согласия. Для перехода со старых сборок с уже загруженным обновлением также показывается подтверждение перед установкой. Совсем старые EXE без модуля обновления нужно один раз заменить вручную.
